# Tour de Force Green Initiative (TFGI)

A modern, responsive website for Tour de Force Green Initiative — a youth-led NGO based in Livingstone, Zambia, dedicated to climate justice and environmental sustainability.

## 🌍 About TFGI

Tour de Force Green Initiative is committed to:
- Eradicating climate change
- Promoting climate justice
- Empowering youth (ages 16–29)
- Building sustainable communities

**Founded:** June 12, 2024  
**Founder:** Matongo Miles Munyama  
**Location:** Livingstone, Zambia

## 📊 Current Impact

- **50+ Trees Planted** through the Green Livingstone Tree Drive
- **50+ Youth Trained** via our Climate Academy
- **6 Active Programs** addressing climate action

## 🎯 Key Programs

1. **Green Livingstone Tree Drive** – Community tree planting initiative
2. **Climate Academy** – Youth training workshops on climate science & advocacy
3. **Community Clean-Up Campaign** – Quarterly environmental action drives
4. **Solar Access for Schools** – Bringing renewable energy to rural schools
5. **Climate-Smart Farming** – Training for sustainable agriculture
6. **Youth Leadership Program** – Leadership development & mentorship

## 🏗️ Technology

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Design:** Responsive, mobile-first
- **Accessibility:** WCAG-compliant with semantic HTML
- **Performance:** Lazy-loaded images, optimized animations

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tour-de-force-green-initiative.git
   cd tour-de-force-green-initiative
   ```

2. Open in your browser:
   ```bash
   # On Windows
   start tfgi_website_v2.html
   
   # On macOS
   open tfgi_website_v2.html
   
   # On Linux
   xdg-open tfgi_website_v2.html
   ```

### Deployment on Vercel

1. **Connect your GitHub repository to Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Sign in with your GitHub account
   - Click "Add New" → "Project"
   - Select the TFGI repository
   - Click "Import"

2. **Configure deployment settings:**
   - Framework: None (Static Site)
   - Root Directory: `.`
   - Build Command: (leave empty)
   - Output Directory: (leave empty)
   - Click "Deploy"

3. **Your site will be live at:** `https://your-project-name.vercel.app`
